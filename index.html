Umami Package Skill

A reproducible Green workflow for one production-oriented Umami web analytics server with colocated PostgreSQL 17, protected behind Caddy and Cloudflare on a guarded DigitalOcean Droplet.

Private service boundary. Only HTTPS and restricted key-only SSH are public. Umami port 3000 and PostgreSQL port 5432 remain inside the Docker Compose network.

Quick start

Build renders reproducible output and dry-run walks the workflow without provider side effects. Real creation and deletion require explicit authorization.

Architecture and sizing

Infrastructure

OpenTofu discovers the configured region’s existing default VPC and creates one Ubuntu 24.04 Droplet and firewall. No VPC is created or hard-coded.

Runtime

Ansible converges a private Docker Compose stack containing Umami (v2.14.0), PostgreSQL 17, and Caddy. Persistent PostgreSQL data lives under /var/lib/umami/postgres.

Network

Cloudflare publishes the DNS record and Caddy terminates origin TLS. Umami port 3000 and PostgreSQL port 5432 never cross the host boundary.

Capacity

The desired four-vCPU, 8 GiB Droplet in ams3 provides ample capacity for high-throughput event ingestion, PostgreSQL buffering, Caddy reverse-proxying, and automated backups.

The package pins Umami Server v2.14.0, PostgreSQL 17-alpine, and Caddy 2.11.4.

Desired state and lifecycle

Non-secret configuration belongs only in colors.yml. It describes the profile, DigitalOcean compute and SSH boundary, DNS, backend, Umami host, backup storage, and retention.

Acceptance and operations

The live convergence verifies the /api/heartbeat health endpoint, ingests a synthetic test event via the /api/send beacon API, and exercises the automated backup service.

ssh root@SERVER 'cd /opt/umami && docker compose ps'
ssh root@SERVER 'cd /opt/umami && docker compose logs --tail=200 umami postgres caddy'
ssh root@SERVER 'systemctl status umami-backup.timer'

Backup, restoration, and disaster recovery

A systemd timer triggers /usr/local/sbin/umami-backup, which executes a consistent pg_dump against the PostgreSQL container, compresses the stream, and uploads it via rclone to Cloudflare R2.

Single node is durable, not highly available. A host, disk, region, or operator failure causes downtime. Backup RPO is the timer interval and restoration is manual; the prevent-destroy guard does not replace a tested recovery exercise.
